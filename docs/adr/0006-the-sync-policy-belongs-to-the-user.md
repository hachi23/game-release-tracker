# What to track is the user's choice, not built in

Early versions had one person's taste built in: a fixed list of publishers, PC and Xbox only, and no sports games. For a public release these became settings (tracked publishers, platform families, a track-from date and opt-in auto-sync), and a new library starts tracking nothing. This costs a new user a setup step, which the sample library and "Add suggested publishers" make up for, but it means the app never shows someone else's idea of what is worth watching.
